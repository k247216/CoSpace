# CoSpace 界面与收集报表

2026-11-25。界面采用米白纸感底色、深绿主色和陶土色点缀，以文件整理和团队交付为主要操作场景。前端继续使用 Vue 3、Element Plus 和 Vite，品牌标记与插画为本地 SVG，字体使用系统字体栈。

## 页面与组件

- `src/styles/cospace.css` 管理主题变量、工作台布局、通用页面与控件样式，以及原个人文件组件的样式衔接。
- `components/cospace` 提供品牌、图标和认证页面布局。登录、注册和密保找回密码共享布局，操作直接调用原用户接口。
- 工作台使用左侧导航、顶部账号菜单和独立滚动的内容区域；手机端导航可展开和关闭。团队页按文件、收集任务、成员和分享分区。
- `collection-manager.vue` 负责创建、邀请和任务管理，`collection-report.vue` 统一显示人员提交情况与文件记录，详情页和管理弹窗复用报表。
- 团队文件列表与搜索返回来源信息，可筛选普通上传或收集文件；同一目录的收集文件显示任务名称。

## 收集信息的含义

提交状态从已完成登记的提交记录汇总得出，不额外维护容易与文件登记失步的布尔状态。“已提交”指该人员至少完成一次业务登记，既包括当前文件，也包括已回收或删除后的历史提交。当前受邀人员按邀请仍然启用统计；撤销后的历史提交单独保留在人员列表及文件总数中。是否还能继续上传，仍由当前成员资格、邀请代次、截止时间和收集状态判定。

管理员可以查看受邀用户名、提交状态、提交文件名、最近提交时间，并筛选未提交或已提交人员。文件清单展示提交时的文件名、大小、提交人和时间。可用文件可由管理员通过团队鉴权接口下载。提交者只查询自己的记录。

提交记录在文件登记事务内保存文件名和大小快照。团队文件之后改名或彻底删除，快照仍保留。`available` 说明当前逻辑文件尚在正常文件树中，实际下载还会重新鉴权并核对父目录。彻底删除后，报表显示已回收或删除并关闭下载入口。

来源根据提交记录中的逻辑文件 ID 关联，而非文件名前缀、当前目录或物理对象 ID。普通上传即使与收集文件内容相同，也有独立逻辑引用和正确来源；来源标记不改变原容量结算与物理清理规则。

## 升级与历史记录

已有库应用 `20261125_collection_reporting.sql`，增加提交快照列及逻辑文件 ID 唯一索引。回填优先读取上传任务的原文件名和大小，再尝试现存逻辑文件。无法恢复的旧记录明确显示名称或大小未保留。

部署前检查重复逻辑文件引用并备份数据库。字段增量兼容旧应用；切换后重复执行只补空值的回填，覆盖旧应用在切换窗口内写入的记录。已有快照不会因重复回填或文件改名而被覆盖。

## 验证

后端完整隔离回归 211 项通过，前端上传编排 18 项通过。新增验证覆盖：两名受邀者的已交/未交状态、普通与收集来源、文件名与大小快照、改名和彻底删除后的历史保留，以及报告授权隔离。回填与重复回填另通过真实 MySQL 的 10 项团队链路检查。

独立浏览器会话验收注册、错误密码提示、登录、改密、退出和密保找回；团队页面验收创建空间、成员管理、多选收集、外部受邀者从列表进入提交、进度刷新、人员筛选、文件来源筛选和报表下载内容一致。桌面及手机视口检查页面宽度与弹窗边界，窄屏表格保留内部横向滚动。

视觉记录位于 `output/playwright/cospace-redesign/`。这些截图用于界面复核；运行与存储验收结果单独记录于部署文档。

## 首页与界面收简

Logo 指向工作台默认子页 `/`，默认子路由命名为 `Home`。首页展示产品介绍，并提供个人文件、团队空间和收集入口。移除导航组件挂载时的跳转副作用，解决在已有布局中点击 Logo 后只渲染外层、内容区空白的问题。已登录访问登录页时也明确转到 `Home`，避免只匹配布局父路由。

工作区保留一个页面标题，去掉重复面包屑式顶栏、英文眉题和装饰口号。账号区只保留用户名与菜单，导航和品牌采用简化的单色图标。宣传文案集中在首页与认证页面。

个人和团队容量复用 `capacity-bar.vue`，总占用为已用加预占，两段颜色分别表示实际使用和进行中的上传。百分比使用原始比例；不足 0.1% 显示对应提示，正数占用的色段保留最小 3px 以便观察，数值及无障碍文本仍使用真实容量。上传完成、取消与空间刷新继续读取原配额接口，不改变结算规则。
